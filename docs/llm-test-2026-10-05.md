## Lessons
- Bigger ≠ slower: gpt-oss (20B, mixture-of-experts, ~3.6B active per token) is ~2× faster than dense Gemma 12B.
- "Thinking" models can use the whole token budget before answering; thinking length varies run to run. Allow ≥ 6000 tokens for reasoning prompts.
- Neither model is safe for unchecked arithmetic or medical text.
- Script bug fixed during the test: images must be piped to `jq` (`base64 | jq -Rn … [input]`), not passed as a command-line argument (Linux "Argument list too long").
- Only 5 prompts, one run each: a first impression, not a verdict.
